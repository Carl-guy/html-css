Principais formatações de Textos

Negrito / Destaque

Para deixar o texto em negrito pode se utilizar a tag B (não semântica), ou Strong (semântica), utilize a tag <strong> por ser semântica e dar significado ao conteúdo, "é negrito por ser FORTE" (strong)

Itálico / Enfase

Para deixar o texto em itálico, utilize a tag <i> (não semântica) ou emphasis (semântica), utilize a tag <em>

Marcação

Para deixar o texto marcado, utilize a tag <mark>.

Riscado / Tachado

Para deixar o texto riscado ou tachado, utilize a tag <del> (não semântica) ou <s> (semântica), utilize a tag <s>.

Texto grande e pequeno

Para deixar o texto em letras grandes utilize a tag <big> (não semântica) ou letras pequenas utilize a tag <small> (semântica).

Texto deletado

Para deixar o texto deletado, utilize a tag <del>.

Texto inserido

Para deixar o texto inserido, utilize a tag <ins> (semântica), existe também a tag <u> (não semântica).

Texto sobrescrito

Para deixar o texto sobrescrito, utilize a tag <sup> (semântica).

Texto subscrito

Para deixar o texto subscrito, utilize a tag <sub> (semântica).
